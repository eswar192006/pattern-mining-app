Put the SPMF jar here, named exactly:  tools/spmf.jar

1. Open the official download page: https://www.philippe-fournier-viger.com/spmf/download.php
2. Under "Release version", download spmf.jar
3. Save it as pattern-mining-app/tools/spmf.jar
4. Check it works:  java -jar tools/spmf.jar   (a window opens; close it)

SPMF is free, open-source software (GNU GPL v3). It is used for high-utility
itemset mining (Step 5). It is not committed to git (see .gitignore).
